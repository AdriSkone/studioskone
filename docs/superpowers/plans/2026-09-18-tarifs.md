# Refonte de l'offre et des tarifs — plan d'implémentation

> **Pour les agents :** SOUS-SKILL REQUISE — utiliser superpowers:subagent-driven-development (recommandé) ou superpowers:executing-plans pour exécuter ce plan tâche par tâche. Les étapes sont des cases à cocher (`- [ ]`).

**But :** remplacer les trois offres du site par trois formules à prix fermes (Une page 900 €, Site complet 1 900 €, Sur mesure dès 3 000 €) et aligner tout le site — accueil, meta, données structurées, pages prestations, estimateur, CGV — sur cette grille.

**Architecture :** le site est généré. Le contenu vit dans `scripts/contenu/*.mjs`, le HTML sort de `scripts/build-*.mjs`, le style dans `src/styles/`. Aucun `.html` n'est édité à la main : il est écrasé au prochain build. Le calcul de l'estimateur est un module pur (`src/components/estimator-pricing.ts`) couvert par Vitest ; le reste est vérifié par quatre scripts qui comparent la page rendue à la version de `main`.

**Tech :** TypeScript vanilla, Vite (MPA), CSS écrit à la main, GSAP + ScrollTrigger, Vitest.

**Spec :** `docs/superpowers/specs/2026-09-18-tarifs-design.md`

## Contraintes globales

- **Les `.html` ne s'éditent jamais à la main.** Lancer le générateur concerné : `node scripts/build-accueil.mjs`, `build-prestation-pages.mjs`, `build-projet-pages.mjs`, `build-404.mjs`, `build-legal-pages.mjs`.
- **Tokens uniquement.** Aucune couleur, fonte, durée ou rondeur en dur : tout vient de `src/styles/tokens.css`.
- **Interdits visuels :** aucune ombre, aucun dégradé, aucun flou, aucun aplat en couleur d'accent sous du texte, aucune icône, aucun badge en pilule. Rayon 16 px sur les blocs, 10 px sur les éléments interactifs.
- **Contrastes :** sur papier, le gris `#5F6468` est à 4.67 sur papier ombré — ne jamais l'assombrir. Sur sombre `#121A20`, seuls le papier (15.02) et l'accent clair (6.60) portent du texte.
- **Copy :** tout texte ajouté, retiré ou remplacé doit être déclaré dans `scripts/verifier-copy.mjs` avec sa raison. Le script compare à `git show main:<fichier>` : il refuse tout ce qui n'est pas déclaré.
- **SEO :** `scripts/verifier-seo.mjs` refuse toute balise ajoutée ou retirée, et n'accepte une valeur modifiée que si elle est déclarée dans `CHANGEMENTS_DECLARES`.
- **Chaînes exactes à utiliser, sans les reformuler :**
  - « Livré en 5 jours ouvrés, à partir du moment où j'ai vos textes et vos photos. »
  - « Livré en 3 semaines, à partir du moment où j'ai vos textes et vos photos. »
  - « Le studio démarre. Sur les prochains projets, −30 % sur les formules Une page et Site complet, en échange d'un témoignage et de l'autorisation de publier le projet. »
  - « Recommandé si vous avez plusieurs services à présenter. »
- **Prix :** 900 €, 1 900 €, à partir de 3 000 €. Design seul dès 600 €, rédaction 200 € la page, photo sur devis.
- **Avant chaque commit :** `npm run build`, puis les quatre vérificateurs et les tests. Un lot n'est jamais poussé sur `main` : il part sur la branche, Vercel en fait une prévisualisation, et Adri valide.
- **Messages de commit :** en français, ils disent pourquoi et non quoi, et se terminent par `Co-Authored-By: Claude Opus 5 (1M context) <noreply@anthropic.com>`.

```ts
export type SiteType = 'vitrine' | 'vitrine-plus' | 'boutique' | 'application'
export type SizeChoice = '1' | '2-5' | '6-12' | 'inconnu'
export type ContentChoice = 'pret' | 'partiel' | 'a-creer'

export type EstimateInput = { type: SiteType; size: SizeChoice; content: ContentChoice }

export type Formule = 'Une page' | 'Site complet' | 'Sur mesure'

export type Estimate = {
  formule: Formule
  /** Prix ferme de la formule, ou null quand il n'y en a pas (application). */
  prix: number | null
  /** true quand le prix s'annonce « à partir de » : périmètre au-delà de la formule. */
  prixDepuis: boolean
  showPrice: boolean
  delay: string
  /** Une seule phrase d'ajustement, ou null. Jamais deux à la fois. */
  ajustement: string | null
  projectType: 'vitrine' | 'ecommerce' | 'app-web'
  budget: '1k-3k' | '3k-5k' | '5k-10k' | '10k+' | 'a-def'
}

// Les prix fermes de la grille tarifaire. Le module ne calcule plus de
// fourchette : la promesse du site est un prix ferme, pas une estimation.
const PRIX: Record<Formule, number | null> = {
  'Une page': 900,
  'Site complet': 1900,
  'Sur mesure': 3000,
}

const DELAI: Record<Formule, string> = {
  'Une page': '5 jours ouvrés',
  'Site complet': '3 semaines',
  'Sur mesure': 'défini au cadrage',
}

const PROJECT_TYPE: Record<SiteType, Estimate['projectType']> = {
  'vitrine': 'vitrine',
  'vitrine-plus': 'vitrine',
  'boutique': 'ecommerce',
  'application': 'app-web',
}

export function estimate(input: EstimateInput): Estimate {
  const projectType = PROJECT_TYPE[input.type]

  if (input.type === 'application') {
    return {
      formule: 'Sur mesure', prix: null, prixDepuis: true, showPrice: false,
      delay: DELAI['Sur mesure'], ajustement: null, projectType, budget: 'a-def',
    }
  }

  if (input.type === 'boutique') {
    return {
      formule: 'Sur mesure', prix: PRIX['Sur mesure'], prixDepuis: true, showPrice: true,
      delay: DELAI['Sur mesure'], ajustement: null, projectType, budget: '3k-5k',
    }
  }

  const unePage = input.type === 'vitrine' && input.size === '1'
  const formule: Formule = unePage ? 'Une page' : 'Site complet'

  // « À partir de » dès que le périmètre dépasse la formule : réservation
  // ou devis en ligne, plus de six pages, ou taille encore inconnue.
  const prixDepuis =
    input.type === 'vitrine-plus' || input.size === '6-12' || input.size === 'inconnu'

  // Une seule phrase d'ajustement, par ordre de priorité : le périmètre
  // d'abord, les contenus ensuite.
  const ajustement =
    input.size === '6-12'
      ? 'Au-delà de six pages, on ajuste ensemble.'
      : input.content === 'a-creer'
        ? 'Rédaction des textes en option : 200 € par page.'
        : null

  return {
    formule,
    prix: PRIX[formule],
    prixDepuis,
    showPrice: true,
    delay: DELAI[formule],
    ajustement,
    projectType,
    budget: input.size === 'inconnu' ? 'a-def' : '1k-3k',
  }
}
```

  function cocher(nom: string, valeur: string): boolean {

    if (!champ) return false
